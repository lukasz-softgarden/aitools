## LLM Basics — Slidev Presentation

Commands:

```bash
cd docs/presentations/20250807_ai_presentation/src
npm i
npm run dev
```

Build/export:

```bash
npm run build   # static site
npm run export  # PDF
```

Slides reference the sibling `img/` directory using relative paths.

Docs: [Slidev](https://sli.dev/)
