# GitHub Copilot ChatModes

## Global Chat Modes

Stored in: `~/Library/Application Support/Code/User/prompts` 

## Repo Chat Modes

Stored in: `/path/to/repo/.github/chatmodes`

## Plan & Implement Workflow

### 1. Plan Mode
First, select `Plan` mode and explain what has to be done:
- Describe the task or feature requirements
- Iterate and polish the plan

When the plan is ready, ask to store it as a file for future reference.

### 2. Implement Mode
Switch to `Implement` mode (preferably in a new chat window for clean context):
- Ask to implement changes according to the selected plan file
- Reference the stored plan throughout implementation
- Follow the plan step-by-step while maintaining flexibility for adjustments
